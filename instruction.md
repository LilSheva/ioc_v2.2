## IOC Parser v2.2 — Руководство пользователя

### Общее описание

IOC Parser — программа для извлечения индикаторов компрометации (IOC) и идентификаторов уязвимостей (BDU/CVE) из бюллетеней в формате Word (.docx).

Поддерживаются два источника:
- **ФСТЭК** — бюллетени ФСТЭК России (обфусцированные IOC)
- **ГосСОПКА** — бюллетени ГосСОПКА (смешанная обфускация, определение статуса)

### Быстрый старт

1. Запустите программу
2. На вкладке **Главная** нажмите **«Выбрать файлы»** и укажите один или несколько `.docx` файлов
3. Выберите режим: **ФСТЭК** или **ГосСОПКА**
4. Для ФСТЭК — заполните поле **«Номер бюллетеня»**; для ГосСОПКА — поля заполняются автоматически
5. Нажмите кнопку **«Сгенерировать отчёт»**
6. Выберите папку для сохранения файлов

### Режимы работы

- **ФСТЭК** — извлекает обфусцированные IOC из бюллетеней ФСТЭК. Все IOC считаются подлежащими блокировке. Номер бюллетеня указывается вручную.
- **ГосСОПКА** — извлекает IOC из бюллетеней ГосСОПКА со смешанной обфускацией. Автоматически определяет статус каждого IOC: **блокировка**, **поиск** или **разблокировка**. Метаданные (организация, дата, номера) извлекаются из документа автоматически.

### Типы IOC

Программа распознаёт следующие типы индикаторов:

- **IP** — IP-адреса (IPv4)
- **DNS** — доменные имена
- **URI** — URL-адреса (домены из URI попадают в DNS, IP из URI — в группу IP)
- **File** — имена файлов
- **Email** — адреса электронной почты
- **SHA256** — хеш-суммы SHA-256
- **SHA1** — хеш-суммы SHA-1
- **MD5** — хеш-суммы MD5
- **Registry** — ключи реестра Windows

### Вкладки программы

- **Главная** — выбор файлов, параметры отчёта, лог обработки, кнопка генерации
- **Настройка IOC** — включение/отключение типов IOC, редактирование регулярных выражений и шаблонов запросов, сброс к настройкам по умолчанию
- **Результаты запросов** — поисковые запросы для MP10 и NAD в формате `field in [...]`, разбивка на чанки, копирование в буфер
- **IP управление** — списки IP на блокировку и разблокировку, кнопки копирования для настройки межсетевого экрана
- **Инструкция** — эта страница

### Выходные файлы

После генерации создаются следующие файлы:

- **Отчёт (.xlsx)** — основной отчёт с найденными IOC, их типами, статусами и контекстом из документа
- **Фильтры (.xlsx)** — таблица фильтров для систем MP10 и NAD, каждый шаблон — отдельный столбец с подставленными значениями
- **BDU (.txt)** — список идентификаторов уязвимостей BDU/CVE (если найдены в документе)

### Настройки

- Настройки сохраняются в файл `ioc_parser_settings.json` только при явном нажатии кнопки **«Сохранить»**
- Каждый тип IOC можно сбросить к значениям по умолчанию кнопкой **«Сброс»**
- Кнопка **«Сбросить все»** возвращает все типы IOC к настройкам по умолчанию
- Шаблоны запросов задаются для двух систем:
  - **MP10** — формат `field in ["v1", "v2"]`, разделитель ` OR`
  - **NAD** — формат `field in ["v1", "v2"]`, разделитель ` ||`

### Режим очистки URI

В настройках URI доступны два режима очистки:

- **domain** — из URI извлекается только доменное имя
- **unique** — сохраняются уникальные пути URI (с портами)
