# IOC Parser

**IOC Parser** — инструмент предназначенный для автоматического извлечения индикаторов компрометации (IOC) из неструктурированных отчетов в формате Word (`.docx`). Утилита формирует структурированные Excel-отчеты и генерирует готовые поисковые запросы для SIEM-систем и NAD.

---

## 📋 Инструкция по использованию

1.  **Настройка:**
    *   На вкладке **«Главная»** выберите режим (**ФСТЕК** или **ГосСОПКА**).
    *   Выберите режим очистки URI:
        *   *До уникального префикса* (сохраняет путь: `site.com/path`).
        *   *Только домен* (обрезает до: `site.com`).
2.  **Загрузка данных:**
    *   Нажмите **«Добавить файлы»** и выберите документы `.docx`.
3.  **Генерация:**
    *   Нажмите **«Сформировать отчеты»**.
4.  **Результат:**
    *   В выбранной директории будут созданы отчеты, а в окне лога отобразится статистика.

---

## 📂 Структура выходных данных

После завершения работы создаются три файла:

1.  **Основной отчет (`.xlsx`)**
    *   Сводная таблица со всеми найденными IOC, статусами (из конфига), номерами бюллетеней и типами событий.
2.  **Файл запросов (`_queries.txt`)**
    *   Текстовый файл с готовыми запросами для вставки в SIEM (MP10) и NAD. Шаблоны запросов настраиваются в `config.txt`.
3.  **Файл фильтров (`Фильтры...xlsx`)**
    *   Генерируется только при наличии шаблона `tst/Фильтры (Переделанные).xlsx`.
    *   Содержит IOC, распределенные по листам (IP, DNS, Hash) для загрузки в средства защиты.

## 🔧 Конфигурация // Пользоваться крайне аккуратно и локально (не менять на сетевом диске)

### Быстрая настройка (GUI)
На вкладке **«Настройка IOC»** можно:
*   Включать/отключать поиск определенных типов IOC.
*   Менять приоритет отображения в отчете.
*   Редактировать статусы по умолчанию (NTA/SIEM).

### Продвинутая настройка (`config.txt`)
Файл `config.txt` содержит JSON-структуру для управления логикой:
*   **regex:** Регулярные выражения для поиска.
*   **mp10_templates / nad_templates:** Шаблоны генерации поисковых запросов.
*   **file_blacklist:** Исключение файлов по контекстным словам (например, "тематика").
*   **filename_exclusions:** "Черный список" имен файлов (например, `1.docx`, `test.exe`).

> **Важно:** Порядок извлечения IOC в ядре программы фиксирован для предотвращения ошибок:
> `Email` → `URI` → `IP` → `Files` → `DNS` → `Hashes`
