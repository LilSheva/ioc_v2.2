# STACK: Ограничения по библиотекам и технологический стек

Проект спроектирован так, чтобы внешние зависимости не проникали в ядро бизнес-логики. Это минимизирует риски поломки ядра при обновлении сторонних пакетов и упрощает компиляцию в исполняемый файл `.exe` через PyInstaller.

---

## 1. Ограничения ядра (`ioc_analyzer/core/`)
Внутри папки `core/` разрешено использовать **исключительно стандартную библиотеку Python**. 
* **Категорически запрещен импорт:** `openpyxl`, `docx`, `requests`, `exchangelib`, `win32com`, `ttkbootstrap` или любых других сторонних пакетов.
* Разрешенные модули стандартной библиотеки: `re`, `os`, `sys`, `json`, `logging`, `urllib.parse`, `collections`, `typing`, `datetime`, `abc`, `functools`, `time`, `shutil`.

---

## 2. Разрешенные зависимости в адаптерах (`ioc_analyzer/adapters/`)
Внешние библиотеки могут использоваться только внутри соответствующих адаптеров:

### 2.1. Документы (docx)
* Библиотека: `python-docx` (импорт как `docx`).
* Используется в: `adapters/document/docx_adapter.py`.
* Назначение: Чтение параграфов, извлечение XML-свойств абзацев (`w:pPr`) для детекции границ.

### 2.2. Почта Exchange (EWS)
* Библиотека: `exchangelib`.
* Используется в: `adapters/mail/exchange_adapter.py`.
* Назначение: Подключение к почтовому серверу MS Exchange, выборка непрочитанных писем, загрузка вложений, отметка писем как прочитанных.
* Заменяет устаревший `win32com.client` (Outlook COM Automation).

### 2.3. Таблицы и Отчеты
* Библиотека: `openpyxl`.
* Используется в: `adapters/export/excel_report.py`.
* Назначение: Создание файлов `.xlsx`, форматирование шрифтов, границ, выравнивание ячеек, автоподбор ширины столбцов.

### 2.4. Интеграция с SIEM API
* Библиотека: `requests`.
* Используется в: `adapters/siem/api_adapter.py`.
* Назначение: Отправка HTTP-запросов (POST/GET) для интеграции с API SIEM.

### 2.5. Интерфейс пользователя (GUI)
* Библиотека: `ttkbootstrap` (надстройка над `tkinter`).
* Используется в: `adapters/gui/tkinter_gui.py`.
* Назначение: Создание премиального графического интерфейса с поддержкой стилей и вкладок.

---

## 3. Сборка проекта
Для компиляции в единый исполняемый `.exe` файл используется `PyInstaller` со следующими параметрами (концептуально):
- `--onedir` или `--onefile`
- `--noconsole` (для `run_gui.py`)
- `--collect-data ttkbootstrap`
- `--hidden-import exchangelib`
- `--hidden-import openpyxl`
- `--hidden-import docx`
